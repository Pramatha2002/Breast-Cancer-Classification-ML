# Breast Cancer Classification Using Machine Learning

## Project Overview

This project uses machine learning to classify breast tumors as **benign or malignant** based on diagnostic features.

## Objective

To build and compare machine learning models and identify the model with the best classification performance.

## Tools and Technologies

* Python
* Pandas and NumPy
* Matplotlib
* Scikit-learn
* Google Colab

## Dataset

The project uses the Wisconsin Diagnostic Breast Cancer dataset.  source link :https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data .

## Project Workflow

1. Data loading and cleaning
2. Exploratory data analysis (EDA)
3. Data visualization
4. Train-test split
5. Model training using Logistic Regression, Decision Tree, and Random Forest
6. Model evaluation and comparison
7. Feature importance analysis

## Model Comparison

| Model               | Accuracy |
| ------------------- | -------: |
| Logistic Regression |   96.49% |
| Decision Tree       |   92.98% |
| Random Forest       |   97.37% |

## Key Findings

* Random Forest achieved the highest test accuracy of 97.37%.
* Feature importance analysis was performed for the tree-based models.
* The three models were compared to understand their classification performance.

## Conclusion

This project provided practical experience in data cleaning, exploratory data analysis, visualization, machine learning, and model evaluation.

**Note:** This project is for educational purposes only and is not intended for clinical diagnosis.
